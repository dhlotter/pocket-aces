# Accessibility Scan — Pocket Aces

- **Date:** 2026-09-23   **Engine:** axe-core 4.10.2 (WCAG 2.2 AA)
- **Routes scanned:** 4 DOM states: setup, tournament, schedule modal open, pause overlay open
- **Totals before fixes:** 5 violation rules, 40 elements. **After fixes:** 0 violations across all 4 states

> Automated scan via axe-core. Catches ~50-57% of WCAG issues; manual review still
> needed for focus order, alt-text quality, and reading sequence.

## Summary by severity (before fixes)

| Severity | Rules | Elements |
|---|---|---|
| Critical | label, select-name, meta-viewport | 28 |
| Serious | color-contrast, scrollable-region-focusable | 12 |

## Findings and fixes

### 1. Zoom disabled on mobile — `meta-viewport` · critical · WCAG 1.4.4
- **Where:** all states, 1 element
- **Why it fails:** `user-scalable=no` plus `maximum-scale=1` on the viewport meta disables pinch zoom
- **Fix applied:** viewport is now `width=device-width, initial-scale=1`

### 2. Form fields without labels — `label`, `select-name` · critical · WCAG 4.1.2 / 1.3.1
- **Where:** setup, 27 elements (20 chip table inputs, buy-in, re-buy, max re-buys, re-buy window select, 3 payout inputs, player name inputs)
- **Why it fails:** no associated label, aria-label, or title
- **Fix applied:** explicit `<label for>` on the tournament fields, aria-label on chip, payout and player inputs

### 3. Contrast below 4.5:1 — `color-contrast` · serious · WCAG 1.4.3
- **Where and what:**
  - section titles: `--gold-dim` #8a7434 on #0f180f = 3.99:1
  - chip value on the green chip dot: white on #2d9e2d = 3.47:1
  - resume banner text: `--text-secondary` #8a8274 on #162116 = 4.37:1
  - schedule break rows: secondary text on #0d3d1d = 3.70:1
- **Fix applied:** `--gold-dim` brightened to #a08544 (5.1:1), `--text-secondary` to #948c7d (5.0:1 on its darkest surface), green chip now renders dark text (6.1:1), break rows use #b8b0a0 (5.7:1)

### 4. Scrollable regions unreachable by keyboard — `scrollable-region-focusable` · serious · WCAG 2.1.1
- **Where:** hand rankings column, chips and prize pool column, blind schedule modal body
- **Why it fails:** scrollable area with no focusable content cannot be scrolled from the keyboard
- **Fix applied:** `tabindex="0"` with `role="region"` and an aria-label on each

## Needs review (manual)

- `color-contrast` incomplete, up to 69 elements per state: icon-only buttons (move up, move down, eliminate, paid toggle, remove) contain only non-text glyphs, so axe cannot resolve their contrast. The glyphs use the same tokens as the passing text (#948c7d on near black, 5.0:1 by calculation), so they are expected to pass; confirm visually.
- Not covered by automation: focus order across the setup grid, reading sequence of the tournament columns, dismiss behavior of the storage warning.

## Scan states

Tournament and later states were driven from a live saved game (3 players, level 1) so the resume banner, player cards and prize pool were all present during scanning.
